## Вкладка «Модели»

- Маршрут: `/assistants/:id` → вкладка **Модели**
- Источник данных: `GET /models` (каталог платформы)
- Если в `settings.modelChain` есть ID моделей — показывается цепочка с бейджами «Основная / Резервная / Fallback» и статусом **Настроено**
- Если цепочка пуста — пустое состояние «Модели не настроены» + блок-предпросмотр с примерами GPT/Claude/Gemini (**Не настроено**)
- Сохранение цепочки не реализовано (Stage 2+ runtime)

## Статус настройки (готовность)

Формула (база 15%, макс. 100%):

| Критерий | Вес |
|----------|-----|
| Основное: название + тип + промпт | +45% |
| Модели: есть запись в `settings.modelChain` | +30% |
| Ключи: ≥1 активный `agt_` ключ | +25% |
| Переменные | необязательно (отображается в чеклисте) |
| Подключения | не учитываются |

| Процент | Метка |
|---------|-------|
| 15–59% | Не настроен |
| 60–99% | Частично настроен |
| 100% | Готов к работе |
